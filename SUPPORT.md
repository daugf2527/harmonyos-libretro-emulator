# Support

## What This File Is For

This repository is primarily an engineering project, not a polished end-user support portal.

Use these paths:

- Bug report: open a GitHub Issue with reproduction details
- Feature request: open a GitHub Issue with the user/problem context
- Security issue: follow [SECURITY.md](SECURITY.md), do not post publicly

## Before Opening an Issue

- Confirm the problem is on the active `new_arch` path.
- Include device / emulator context.
- Include whether the issue was seen with imported user content or internal test flow.
- Attach the exact local checks or logs you already ran.

## Current Limitations

- The project still contains engineering-oriented pages and validation flows.
- Device compatibility depends on core, content, render mode, and system behavior.
- Store-release readiness is still gated by release documents and asset policy.
