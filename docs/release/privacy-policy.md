# 隐私政策

更新时间：2026-07-07

> 说明：这是仓库内发布文案源稿。正式上架前需要发布到可公开访问的网页，并在 AppGallery Connect 后台填写对应 URL。

## 1. 我们提供什么

本应用“碳影（Carbon Shade）”是一个运行在 HarmonyOS 手机上的本地模拟前端壳，用于加载用户自行提供且具有合法使用权的内容文件。

## 2. 我们收集什么

当前版本默认不要求用户注册账号，不提供在线社区、云同步或广告服务。

应用在本地可能处理以下信息：

- 用户主动导入的 ROM / BIOS / 相关内容文件
- 用户在应用内生成的存档、配置、输入布局与运行日志
- 为实现震动反馈而请求的设备震动权限

## 3. 我们如何使用这些数据

上述数据仅用于：

- 在本地设备上运行用户导入的内容
- 保存用户的运行状态、设置和输入布局
- 在本地显示错误信息与调试状态

## 4. 数据是否上传

当前版本默认不将上述内容上传到开发者服务器。

如果未来版本新增联网能力、遥测、崩溃上报、云同步或反馈服务，我们会在功能启用前单独说明收集范围、用途与开关方式，并同步更新本政策。

## 5. 权限说明

- `ohos.permission.VIBRATE`
  - 用途：用于游戏按键触觉反馈，提升操作体验。

若未来新增存储、网络、设备等权限，将在上架前同步更新本节。

## 6. 第三方组件

本应用使用 libretro 前端/核心相关技术组件。第三方组件的许可证、适用范围和限制以各组件随附许可证为准。

## 7. 用户内容与版权责任

应用不提供商业 ROM 下载服务。用户应保证其导入、加载和使用的 ROM、BIOS、核心文件及相关内容拥有合法来源和使用权。

## 8. 联系方式

- 开发者/团队名称：Carbon Shade Project
- 支持入口：https://github.com/daugf2527/harmonyos-libretro-emulator/issues
- 隐私问题受理方式：通过 AppGallery Connect 商店页开发者联系入口，或在 GitHub Issues 中提交不含敏感个人数据的问题说明。

## 9. 生效与更新

本政策在应用正式发布时生效。若后续数据处理方式发生变化，我们会在更新版本时同步调整，并在应用内或商店页提示用户查看更新后的政策。
