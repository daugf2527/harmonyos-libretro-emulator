## 1. 许可范围

本应用向用户提供本地模拟前端壳能力，用于在兼容设备上管理、启动和运行用户自行提供的内容文件。

## 2. 不提供的内容

本应用默认不向用户提供以下内容：

- 商业 ROM 下载
- BIOS 下载
- 受限制内容的在线分发
- 对第三方内容版权合法性的背书

## 3. 用户责任

用户应自行保证其导入、保存、运行或分享的内容拥有合法来源和使用权，包括但不限于：

- ROM
- BIOS / firmware
- 第三方核心文件
- 封面、元数据与其他衍生资源

本应用可能集成第三方开源组件与 libretro 相关核心。不同组件受其各自许可证约束。开发者不对第三方组件的可用性、兼容性或版权状态作额外保证。

## 5. 使用限制

用户不得利用本应用：

- 分发未获授权的内容
- 规避适用法律或平台规则
- 传播恶意文件或非法内容

本应用按“现状”提供。对于因第三方核心、用户自备内容、设备兼容性、系统限制或错误使用导致的运行问题、数据损失或不可用情况，开发者在法律允许范围内不承担额外责任。
