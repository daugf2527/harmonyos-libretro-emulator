## 中文简介草案

碳影是一款面向 HarmonyOS 手机的本地模拟前端壳，提供导入内容、游戏库管理、核心切换、虚拟按键、即时存读档与本地设置能力。应用不提供 ROM 下载服务，适用于管理和运行你拥有合法使用权的本地内容。

## 英文简介草案

Carbon Shade is a HarmonyOS local emulator frontend shell focused on ROM import, library management, core switching, virtual controls, save states, and local runtime settings. The app does not provide commercial ROM downloads and is intended for content that the user is legally entitled to use.
